CHARACTER PICTURES  (optional)

Put pictures straight into this folder (img/). Name each file exactly as shown in the
left column, then add .jpg, .png or .webp on the end. Example: tanjiro.jpg

The game picks them up the next time you open it and shows them everywhere instead of
the kanji seal. Characters without a picture keep their kanji, so you can add a few at a time.

Watch out: most files use the FIRST name, but a few use the LAST name (marked  <-- last name).

TIPS
- All lowercase, no spaces: rengoku.jpg, not Rengoku.JPG or kyojuro.jpg.
- Portrait crop, face in the upper middle, about 400 x 480 px, under 150 KB each.
  The game crops to a tall rectangle, so head-and-shoulders shots look best.
- Good sources for personal use: screenshots from the anime, or character art from
  the Demon Slayer fan wiki.
- These are for playing at home only. If the game is ever shared publicly or sold,
  use original art instead.
